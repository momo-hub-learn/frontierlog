# AIHOT 参照与本次差异

参照站点：https://aihot.news/ ，主题页：https://aihot.news/topics 。

## 原站可直接观察到的组织方式

AIHOT 使用精选、全部动态、热点榜、日报、主题与收藏入口。精选条目展示标题、摘要、推荐理由、信源和时间；主题页分公司与模型、技术方向、内容形态。

本项目只借鉴这种易浏览的信息组织方式，没有复制原站源代码、文章、推荐理由、评分或流量数字。没有仿造热度分、读者数或实时更新时间。

## 本次独立设计

保留 FrontierLog 原有任务能力、发布跟踪与工具入口，新增“行业 → 业务环节 → 资料类型”的正交筛选。医药不是泛健康新闻，制造也不是所有芯片新闻：专题与用户实际研发、文档和工厂业务对应。

文章来源用其各自官方说明与原始材料，AIHOT 不作为医药或制造内容结论的证据。

每条新资料分开存储：来源概述 summary、编辑意义 why、未支持的结论 boundary、原始发布时间 published、核对时间 checked、建议操作 steps、验收问题 metrics。建议清单的勾选不改变 tested 状态。

机器线索采用保守规则，可多标签；本地测试只验证特定规则的行为，不代表行业分类准确率已经评估。正式上线还需要人工标注样本、计算误报与漏报，再扩展规则或可审查的模型分类。
