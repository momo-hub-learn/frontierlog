# Official event preview artwork

These reduced WebP previews identify the corresponding official events and link readers back to the original publisher. Copyright remains with NVIDIA or Apple. The project MIT license does not apply to these third-party images.

Exact official image URLs, referring pages, publisher credits, and the verification date are recorded in `data/activity-feature.json`. The original artwork is not AI-generated or repurposed as evidence of a different event. Only image resizing and WebP encoding are applied. If an image cannot load, the UI falls back to a text identifier without blocking navigation.

Downloads were reviewed on 2026-09-25. Builds use the checked-in images and do not fetch the network. No event video or full article is mirrored.
