# AI坐标 · v0.9 品牌说明

前台品牌收敛为 **AI坐标**，不再同时展示 FrontierLog / AI 到哪了两个名字。仓库仍保留 `frontierlog`，避免迁移 GitHub Pages 地址和已有链接。

## 设计逻辑

- **坐标**回答“AI 现在到哪了”，同时适配热点、模型榜、Benchmark 与垂类主题。
- Logo 使用坐标轴、折线与一个青柠色定位点，不使用 AIHOT 式英文全大写或字母变形。
- 首页 `精选` 改为按日期展开的通用 AI 热点时间线；医药与制造业的专题内容不再混入精选。
- 热度信息强制单行；热度仍为本站编辑信号，不代表全网浏览量。

## 页面关系

- 精选：通用 AI 热点时间线
- 热点榜：按本站热度排序
- 垂类主题：医药、制造业等业务专题
- 模型榜：模型排行 + Benchmark
- Tibo 重置监控：公开公告记录
