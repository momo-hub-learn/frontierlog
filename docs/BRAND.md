# 品牌与头部 v0.5

主字标 FrontierLog，中文副标 AI 到哪了。图形为墨绿圆角底与青柠色递增信号柱，使用 `src/brand.svg`；导航内联 SVG，浏览器标签页使用同图形。没有随包提供字体文件。

品牌区 42px 图标、22px 字标，控制字距并保留中文次级说明。侧栏 260px，内容、行业、评测与模型、个人工作区分组；较矮窗口滚动导航而非截断菜单。资料、贡献、导出等次要入口收进折叠项。

顶部只保留面包屑、快捷搜索、我的关注和 GitHub 图标。内容标题解释当前页面，避免每页堆同一组品牌标语。浅色为默认，深色继续可用；字体和详情保持可读尺寸。

Benchmark 使用与现有主题页面一致的卡片、细线、墨绿和青柠强调，核心信息顺序为任务 → 指标 → 版本/局限 → 操作。没有为“极客感”增加装饰性终端命令或假实时数据。
