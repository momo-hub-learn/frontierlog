01 OmniDocBench

它测什么：表格、正文、公式分别验。

指标与版本：Edit ↓ · TEDS / CDM ↑ / v1.6_full / 固定评估器

业务参考 · 编辑建议：可作为 CSR 与工程文档流程的底层解析测试，之后仍要核对来源和表间逻辑。

不能直接推断：解析得分不是 CSR 数字一致性、事实准确性或监管接受度。

02 RAGBench

它测什么：把检索与回答中的错误拆开。

指标与版本：Relevance / Adherence / Completeness / TRACe / 固定子集

业务参考 · 编辑建议：适合拆解 CSR 证据检索、工程手册问答和企业知识回答的错误。

不能直接推断：对公开标注的拟合不证明私有知识库正确，也不等于验证本体的结构。

03 BioASQ

它测什么：医药知识，要能找得到依据。

指标与版本：MAP / F1 / 分任务评分 / 14B / 2026

业务参考 · 编辑建议：可作为医药证据检索的公开参照，再添加企业术语、授权资料和来源核对。

不能直接推断：生物医学问答不是完整 CSR 写作，更不是临床决策验证。

下一步怎么验证 · 建议

  • 以有授权的输入文档、表格和参考章节建立留出集
  • 核对数字、单位、分母、表间关系与来源位置
  • 由医学写作和统计人员复核一致性、遗漏与不确定内容
  • ICH E3 仅作结构内容参考；不把评估通过称为监管批准
