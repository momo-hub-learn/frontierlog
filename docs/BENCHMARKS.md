# Benchmark 观察站

## 目录不是排行榜

这里描述测什么、用什么指标、如何对齐版本，以及不能推出什么。实时模型结果仍然来自各自官方入口；本站没有将不同单位的分数混成总分。`data/benchmarks.json` 本版禁止 `score`、`rank`、`sota` 和 `best_model` 字段，避免误把目录当作实际跑分记录。

首批 20 项中 18 项为基准/基准组，SECOM 与 C-MAPSS 两项是数据集参考，页面已单独标记。每项带来源、核对日、版本、计分方向、设置、边界和建议检查项。没有声明该集合完整覆盖全行业或代表最新所有版本。

## 目录与事件维护

`items` 为基准；`sources` 为来源；`changes` 为有日期的历史事件；`suites` 为本站编辑建议。没有单一发布日期的持续维护文档保持 `published: null`，不把核对日填成首次发布日。

`checked` 是本次人工查阅时间，不等于完成了运行复现。历史事件保留原始时间；“值得关注”不是自动每日新闻。增加新事件须在来源中核对日期和实际含义。

## 五组业务建议

Agent 交付、CSR 医学写作、靶点研究、晶圆厂、装备制造。公开测试能提供部分任务参考；企业验收必须补充授权、留出业务样本、错误成本、失败情况、人工接管和实际资源消耗。它们不是行业统一标准，也没有完成实测。

CSR 组合采用文档解析、检索回答和生物医学问答作为部分参考，另列 ICH E3 结构内容资料。已核对来源没有提供覆盖完整 CSR 交付的统一公开 Benchmark；这不是对全世界不存在此类评测的断言。不要把医学题得分等同于事实正确性、数字一致性或监管接受。

TDC 指标按具体数据集和划分读取；目标关联与亲和力预测不自动等于靶点机制验证。SECOM 历史关联数据不提供 FDC/APC 的因果控制结论。C-MAPSS 是引擎退化模拟数据，不是晶圆机台；指标、单元划分和提前量由所选协议明确。

## 汇报清单

最多 6 项；比较口径最多 4 项。选择的 ID 可进入 URL；标题和讨论问题仅存本地。输出 Markdown、无脚本 HTML，以及 `frontierlog-evaluation-plan/v1` JSON。计划里的分数、样本数、模型、版本、成本、人工介入和日志初始均为空，不生成伪造实验。

摘要按固定模板组织已核对资料，不调用大模型产生新结论。页面明确区分来源事实、编辑建议与用户备注。导出并不意味着已通过专家审核。

## 技术与安全

实现采用内嵌 JSON + 原生 JavaScript，支持 `file://` 打开和 GitHub Pages 子路径。与原有哈希路由、主题、收藏、模型表、重置日历独立集成。解析 URL 时验证 ID；备份只接收允许的记录 ID 和有限检查项；备注与查询以文本转义呈现。

外链指向 HTTPS 原始资料。没有页面端 API Key、追踪 SDK 或任务执行服务。导入过大文件被拒绝。浏览器不允许本机持久化时提示本次页面有效。

## 自动更新

本版是人工协议快照，`sync.status=manual`，`last_attempt` 与 `last_success` 为空。没有新的定时采集器、外部评分抓取器、benchmark runner 或计算预算。已有模型和行业采集不会自动维护这个目录。

后续加入结果数据，应另建 schema，至少固定基准 commit、题集 revision、子集、运行器、模型版本、工具、权限、推理预算、随机种子、重试、评分器版本与成本。不允许仅用模型名字连接不同设置的分数。
